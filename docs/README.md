# fab_cars Client Setup Guide

This folder contains client-facing documentation to set up the `fab_cars` app from scratch.

Start here:

1. [`01-quickstart`](./01-quickstart.md) - minimal setup to get the first trip created.
2. [`02-configure-settings`](./02-configure-settings.md) - configure doctype-based settings (LLM, prompt, retries).
3. [`03-setup-webhook-ingestion`](./03-setup-webhook-ingestion.md) - connect Gmail/SendGrid (and run the ingestion service).
4. [`04-test-and-monitor`](./04-test-and-monitor.md) - verify end-to-end and monitor failures.
5. [`05-data-model-and-faq`](./05-data-model-and-faq.md) - what the doctypes mean and common questions.
6. [`06-troubleshooting`](./06-troubleshooting.md) - error handling and how to recover quickly.
